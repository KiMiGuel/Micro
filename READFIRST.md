# READFIRST — MicroVault

Start here, in order.

1. **Resume point**: `CHECKPOINT.md` (this repo) — where the last session left off, what's next.
2. **Current-state facts**: `STATUS.md` (this repo) — what's true right now. Edited in place, not a log.
3. **Full backstory**: `~/CCM2/MicroVault/History.md` — read as backstory, not as standing instruction; reconcile contradictions with current judgment rather than carrying stale plans forward as-is.
4. **Agent instructions**: `~/CLAUDE.md` (machine-wide, not project-local — this repo has no CLAUDE.md/AGENTS.md of its own).

## Checkpoint discipline
`CHECKPOINT.md` is a save point, not a notes dump — one file, always current, overwritten (not appended to) each time work pauses. `Status: COMPLETE` when a task finished (points to the next task); `Status: PAUSED` for a clean stop that isn't mid-task; `Status: IN PROGRESS (emergency)` when work stopped mid-task (captures exactly how far in, so the next session resumes inside the task, not from scratch). When superseded, its content becomes a dated entry at the top of `History.md`'s "Recent" section.
